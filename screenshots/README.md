## 📏 Screenshot Specifications

**Resolution:** Minimum 1920x1080  
**Format:** PNG (better quality than JPG)  
**File Size:** Keep under 2MB each  
**Aspect Ratio:** 16:9 preferred

## 🎨 Tips for Great Screenshots:

1. **Full Screen:** Use F11 for clean capture
2. **Clean Browser:** Hide bookmarks bar, close extra tabs
3. **Good AOI:** Choose interesting locations (cities, coasts)
4. **Clear Results:** Make sure timelapse is fully loaded
5. **Professional:** Avoid clutter in the background
